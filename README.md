# Noir

Noir is an adult-only dating app prototype. This public preview contains fictional sample profiles and events. It is not a live dating service: registration, matching, and messages between users are not active.

## Local preview

With Node.js installed, run `node dev-server.mjs` and open `http://127.0.0.1:4173`.

## Backend setup

See [BACKEND_SETUP.md](BACKEND_SETUP.md). Do not publish a Supabase `service_role` key or other server secrets.
